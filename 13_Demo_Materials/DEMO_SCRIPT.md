# Portfolio Demo Script

## 2-Minute Walkthrough

### 0:00–0:20 — Problem

Introduce the challenge of analyzing large, distributed MAUDE reporting data while respecting its limitations.

### 0:20–0:45 — Data Engineering

Show source validation, malformed-record quarantine, key validation, and lineage.

### 0:45–1:10 — Data Model

Explain separate report and device grains and why distinct report counts must be protected from device multiplicity.

### 1:10–1:35 — Power BI

Show Executive Overview, Device/Product Analysis, Event/Reporting Patterns, Data Quality, and Methodology/Limitations.

### 1:35–1:50 — Synthetic Workflow

Show the clearly labeled synthetic review → investigation → CAPA → effectiveness workflow.

### 1:50–2:00 — Close

Emphasize that the solution surfaces reporting patterns and data-quality evidence without presenting MAUDE as proof of incidence, failure rate, or causality.
